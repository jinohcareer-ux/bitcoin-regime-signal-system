# BTC 레짐 신호 프로젝트

Binance BTCUSDT 1시간봉으로 시간대 효과를 조사하고, 수수료·레버리지·청산 조건을 검토한 뒤, 장기 이동평균을 이용한 일일 레짐 신호와 Mac 자동 알림까지 연결한 프로젝트입니다.

## 프로젝트가 발전한 과정

### 1. 최초 매매 가설

처음 확인한 전략은 뉴욕시간 오후 8시 매수 → 다음 날 오전 11시 매도, 2배 레버리지, BTC 가격 -3.5% 손절이었습니다. 레버리지 포지션 기준으로는 수수료 전 약 -7% 손실에 해당합니다.

2017년 8월 17일부터 2026년 1월 4일까지의 초기 결과는 다음과 같았습니다.

| 지표 | 결과 |
|---|---:|
| 초기금액 | $1,000.00 |
| 수수료·펀딩비 적용 전 최종금액 | $2.91 |
| 거래 수 | 3,035회 |
| 승률 | 47.71% |
| 손절 발생 | 470회 |
| MDD | -99.89% |

진입·청산 각각 0.05%의 수수료까지 적용하면 최종금액은 약 $0.0066이었습니다. 이 가설을 기각한 뒤 다른 시간을 임의로 고르는 대신 모든 시간 조합을 조사했습니다.

### 2. 24×24 시간 조합 전수조사

뉴욕시간 기준 매수시간 0~23시와 매도시간 0~23시의 모든 조합, 총 576개를 조사했습니다. 이후 다음 조건까지 확장해 총 17,280개 설정을 비교했습니다.

- 576개 매수·매도 시간 조합
- 1.0×, 1.5×, 2.0× 레버리지
- 손절 없음 및 BTC 가격 기준 2~10% 손절

수수료와 청산 조건을 완전히 반영하기 전에는 오전 1시 매수 → 오후 7시 매도가 가장 강한 시간 조합으로 나타났습니다. 이 초기 결과에서는 $1,000이 약 $379,114로 증가했고, 거래당 평균수익률 +0.242%, 승률 52.78%, CAGR 약 103%, MDD -52.4%, 거래 수 약 3,045회였습니다. 매우 큰 결과였기 때문에 실제 선택 전에 비용과 청산 조건을 다시 적용했습니다.

### 3. 수수료와 청산 조건 적용

진입·청산 각각 0.05%의 수수료를 적용하고, 2배 레버리지는 BTC 약 -50%, 1.5배 레버리지는 약 -66.67%에서 청산된다는 단순 기준을 확인했습니다.

| 전략 | $1,000의 최종금액 | MDD | 청산 |
|---|---:|---:|---:|
| 1.5×, 오전 1시 → 오후 7시, 손절 없음 | $26,092.86 | -85.64% | 표본 내 없음 |
| 2.0×, 오전 1시 → 오후 7시, 손절 없음 | $18,051.18 | -94.51% | 표본 내 없음 |

선택된 1.5배 전략의 단일 거래 중 가장 큰 BTC 하락은 약 -30.79%였습니다. 과거 데이터에서 청산되지 않았더라도 MDD가 매우 크기 때문에 안전한 전략이라는 의미는 아닙니다.

### 4. 2026년 별도 확인

과거 전체 기간에서 선택된 1.5배, 오전 1시 → 오후 7시 전략을 2026년 1월 1일부터 8월 31일까지 $1,000, 전액 복리, 손절 없음, 진입·청산 각각 0.05% 수수료로 확인했습니다.

| 지표 | 2026년 결과 |
|---|---:|
| 최종금액 | $626.18 |
| 총수익률 | -37.38% |
| 거래 수 | 243회 |
| 승률 | 46.91% |
| MDD | -60.32% |
| 청산 | 0회 |

1월부터 8월까지 월별 수익률은 -17.04%, -17.93%, -13.47%, +16.71%, -6.08%, -31.51%, +13.09%, +25.19%였습니다. 수수료가 없을 때의 최종금액은 $902.02였으므로 반복 매매 비용의 영향이 컸습니다. 이 결과를 바탕으로 고정 시간 전략 대신 시장 상태에 따라 노출을 바꾸는 레짐 모델을 도입했습니다.

## 레짐 규칙

모든 판단은 뉴욕시간 기준으로 완전히 끝난 전일 데이터만 사용합니다.

| 레짐 | 조건 | 목표 노출 |
|---|---|---:|
| **Strong Bull** | 종가 > SMA200, SMA50 > SMA200, SMA200 > 20일 전 SMA200 | BTC 1.5× |
| **Bear** | 종가 < SMA200, SMA50 < SMA200, SMA200 < 20일 전 SMA200 | 현금 100% |
| **Neutral** | 나머지 유효한 조합 | BTC 1.0× |

SMA200과 20일 전 SMA200을 모두 계산할 수 없는 초기 구간은 거래 대상에서 제외합니다.

### 각 조건의 의미

- 종가와 SMA200 비교: 현재 가격이 장기 추세 위에 있는지 확인
- SMA50과 SMA200 비교: 중기 추세가 장기 추세보다 강한지 확인
- 현재 SMA200과 20일 전 SMA200 비교: 장기 추세 자체가 상승 중인지 확인
- Bear에서 공매도하지 않고 현금으로 전환해 명확한 하락장에서 노출을 줄임

## 참고 백테스트 결과

개발 과정에서 비교한 기간은 2017년 8월 17일부터 2026년 8월 31일까지입니다.

| 전략 | $1,000의 최종금액 | 총수익률 | CAGR | MDD |
|---|---:|---:|---:|---:|
| 레짐 1.5× / 1.0× / 현금 | $19,831.81 | +1,883% | 39.2% | -85.8% |
| Strong Bull에서만 오전 1시 → 오후 7시, 1.5× | $4,582.88 | +358% | 18.3% | -76.4% |
| BTC 단순 보유 | $18,221.79 | +1,722% | 37.9% | -84.0% |

2026년 1월부터 8월까지 레짐 모델의 참고 결과는 $1,000 → $1,129.84, +12.98%, MDD -4.76%였습니다. 같은 기간 단순 보유는 $895.22, -10.48%, MDD -40.81%였습니다.

위 숫자는 개발 과정에서 얻은 과거 데이터 결과이며 예상수익률이 아닙니다. 데이터 종료일과 비용 및 실행 가정이 바뀌면 결과도 달라집니다.

## 백테스트 코드가 하는 일

`btc_regime_backtest.py`는 다음 순서로 작동합니다.

1. Binance Vision에서 BTCUSDT 1시간봉 다운로드
2. 타임스탬프를 뉴욕시간으로 변환
3. 일광절약시간을 고려해 하루 23·24·25시간 허용
4. 아직 끝나지 않은 오늘의 뉴욕 일봉 제거
5. SMA50, SMA200, 20일 전 SMA200 계산
6. 신호를 하루 뒤로 이동해 미래 데이터 사용 방지
7. 오전 12시 1분 거래를 오전 12시 1시간봉 시가로 근사
8. 레짐에 따라 1.5배·1배·현금 배정
9. 목표 노출이 바뀐 만큼 수수료 적용
10. 복리 자산과 MDD 계산
11. 상세 결과를 `outputs/` 폴더에 CSV와 JSON으로 저장

`DAILY_CLOSE_REOPEN = True`로 바꾸면 매일 포지션을 닫고 다시 여는 것으로 계산하고 매일 양방향 수수료를 부과합니다. 기본값 `False`에서는 목표 노출이 바뀔 때만 수수료를 부과합니다.

## 실시간 신호 코드

`btc_signal.py`는 이동평균 계산에 필요한 최근 데이터를 내려받아 가장 최근에 완료된 뉴욕 일봉으로 다음 신호를 만듭니다.

- 🟢 `STRONG BULL | BUY BTC | 1.5x exposure`
- 🟡 `NEUTRAL | BUY BTC | 1.0x exposure`
- 🔴 `BEAR | DO NOT BUY BTC | CASH`

## 설치와 실행

```bash
python -m pip install -r requirements.txt
python btc_regime_backtest.py
python btc_signal.py
```

## Mac cron 자동 실행

`crontab -e`에서 다음과 같이 설정하면 매일 오전 12시 10분에 실행됩니다.

```cron
10 0 * * * /opt/anaconda3/bin/python /Users/yourname/Bitcoin/btc_signal.py >> /Users/yourname/Bitcoin/btc_signal.log 2>&1
```

Mac이 해당 시간에 켜져 있고 잠자기 상태가 아니어야 합니다. Jupyter는 열어둘 필요가 없습니다.

## 코드 해석 시 주의사항

- 수천 개 설정을 비교했으므로 다중검정과 과적합 위험이 큽니다.
- 레짐 조건도 과거 데이터를 확인한 뒤 선택했으므로 전체기간 결과를 순수한 표본외 성과로 볼 수 없습니다.
- 펀딩비·차입비용·스프레드·슬리피지·세금·주문 실패는 포함하지 않았습니다.
- 현재 레짐 백테스트는 시간봉 고가·저가를 이용한 장중 청산을 구현하지 않았습니다.
- 일일 BTC 수익률에 목표 레버리지를 곱하는 방식은 일일 레버리지 재조정을 근사합니다. 실제로 포지션을 그대로 보유하면 가격에 따라 레버리지가 달라지므로 코인 수량과 현금·부채를 따로 추적해야 합니다.
- 오전 12시 시가는 오전 12시 1분 주문가격의 근사치입니다.
- cron 실행 시각에 Mac이 잠들어 있으면 해당 실행을 놓칠 수 있습니다.

## 면책문구

교육 및 연구 목적의 프로젝트이며 투자 조언이 아닙니다. 과거 성과는 미래 성과를 보장하지 않습니다.
